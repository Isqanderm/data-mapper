## Class-level @Expose / @Exclude

Class-level `@Expose()` / `@Exclude()` (applied to the class itself rather than a field) are
accepted syntactically but are **no-ops** — only field-level usage currently affects
transformation. Don't rely on class-level default-exclude/expose behavior.
